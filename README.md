# Olalekan Ajiboye Portfolio

Next.js portfolio with:
- Home / About / Skills
- 9 project pages
- Resume page
- Downloadable CV PDF
- Responsive dark technical design

## Run
npm install
npm run dev

## Build
npm run build

## Add portrait
Place your photo at `public/profile.jpg` and update the hero in `app/page.tsx` to use `next/image`.

## Links
Replace placeholder GitHub/LinkedIn links when ready.
